# Vaarta style packs

The six demo identities use the same Gutenberg modules, patterns and templates. Style variations change presentation only.

| Style | Editorial character | Heading direction | Surface character |
| --- | --- | --- | --- |
| Tech | crisp, minimal, technology-led | modern sans | cool neutral |
| Firmware | gadget/editorial | modern sans | warm neutral |
| Datacrunch | marketing/data | compact sans | warm paper |
| Foundr | startup/business | editorial serif | warm cream |
| Artboard | creative/freebies | modern sans | soft violet neutral |
| Design Loft | architecture/design | editorial serif | muted natural |

All packs redefine the same palette slugs:

- `canvas`
- `ink`
- `muted`
- `line`
- `surface`
- `accent`

Blocks must consume semantic tokens instead of hard-coded demo colors. That rule is what allows one Editorial Grid, Newsletter, Popup, Review, Search Overlay, Social Feed and article system to work across every visual identity.

The current tokens are first-pass clean-room values. Final values should be adjusted through visual regression against the reference screenshots without copying proprietary source CSS.
